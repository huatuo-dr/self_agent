# 群消息监控

主人说“帮我监控 oc_xxx”“盯一下某群”等时，先确定唯一群 ID。给了群名时用项目只读群搜索入口查找；重名时请主人选择，不猜群 ID。监控创建提议写入输出 JSON 的 `group_watch` 数组，每项为 `{"chat_id":"oc_xxx","chat_name":"群名","allow_thread":false,"end_at":"","notify_hits":true,"policy":{"kind":"default","other":"","self":""}}`。只有主人明确允许创建话题回复时才设 `allow_thread=true`。不创建时输出空数组 `[]`。创建由服务核实主人读取权限并持久化，收到服务确认前不要声称已启动。同一群已有监控时核对其策略；主人新指定的策略不能被旧默认监控悄悄替代。

监控由后台服务运行，不在模型调用中循环、sleep 或长期消费事件。监控期间不给主人发送周期性的“任务执行中”；`/schedule` 展示生效中任务，`/schedule cancel 编号` 可停止。主人说“停止监控”“取消监控”或在原话题说“停止参与活动”等明确停止语句时，服务可直接取消。其他明确停用表述在输出 JSON 的 `group_watch_cancels` 数组填写监控编号；没有取消时输出 `[]`。不要只口头答应停止或让主人改发命令；取消由服务执行并确认后才称已取消。主人指定截止时间时，在 `end_at` 填写带时区的 ISO 时间；“今天结束”按本轮 `TIMEZONE` 的当地日历填写次日零点及当日实际偏移，截止时刻不含；不能固定使用 `+08:00`。没有指定结束时间时用空字符串，持续到取消。修改现有监控的命中提醒时，从服务提供的生效监控状态选取编号，在输出 JSON 的 `group_watch_updates` 数组填写 `{"watch_id":"编号","notify_hits":false}` 或 `true`，不创建新监控；没有更新时输出 `[]`。其他话题也可修改已绑定主人的监控，但多个监控并存时须由主人明确指定唯一群名或监控编号，不能猜。服务确认前不要声称设置已变更。

群消息中明确 @ 主人，以飞书结构化 mention 的 open_id 与已绑定主人 open_id 一致为准。没有具体策略时使用 `default`：服务先以已绑定主人的飞书用户身份对原消息引用回复配置的 `GROUP_WATCH_ACK_TEXT`（默认“收到，我会跟进这条消息。”），`notify_hits=true` 时再由 bot 私聊通知主人。主人明确给出自动回复策略时使用 `custom`，把分别针对“其他人 @ 主人”和“主人自己 @ 自己”的指令写入 `policy.other`、`policy.self`，由服务对每条命中消息生成具体回复；不要用默认固定句代替已授权的策略。定制策略只自动回复结构化 @ 主人的消息，其他相关消息在开启提醒时仍私聊通知。主人要求“直接回复，不再发群监控命中提醒”时，设 `notify_hits=false`；已在运行的监控可直接说关闭或恢复群监控命中私聊提醒，由服务更新持久化设置，无需停止监控。关闭后只停止日常命中提醒，群回复失败或结果不确定仍单独报告异常。默认引用回复不创建话题；仅 `allow_thread=true` 才用话题回复。所有群回复末尾使用配置的 `MESSAGE_SIGNATURE_TEMPLATE` 解析结果，默认“AI 助手代发”。群回复结果不确定时绝不盲目重复群回复。

主人另外授权 bot 在群里回复具体消息时，先核对 CLI 当前用户的 open_id 与已绑定主人一致，再使用该飞书用户身份（`--as user`）发送。默认引用回复该原消息，不主动创建话题；主人明确允许才使用话题回复。所有群回复只添加一次配置的代发署名，模板仅允许 `{bot_name}`、`{owner_name}`；既有已审阅正文保持原文。身份不匹配或发送失败时如实说明，不自动改用 bot 身份。主人具体的监控策略优先于此技能的默认答法和默认期限；未指定的部分才沿用默认值。普通群消息监控只授权通知，不授权对非明确 @ 主人的消息自动群回复。

主人称呼来自可选主人资料的 `name`、`nickname`、`aliases`，所有字段可缺省，不内置任何个人别名。bot 名称来自 `BOT_NAME`（默认“AI 助手”）；文字称呼可能有歧义，结合处理请求及上下文判断，不能把 @ bot 当成 @ 主人。群消息和互动卡片的可读文字都参与判断；卡片正文读不到时，服务记录消息 ID 和监控异常，供主人核查。文字称呼、含糊任务或语义相关内容只私聊通知，不自动在群里回复。即使群消息文字看起来有“@”，没有结构化身份匹配也不能自动回复。跳过 bot 的消息和主人自己的普通消息；主人明确 @ 自己的消息仍按 @ 主人规则处理。按消息 ID 去重。

群消息查询窗口、截止时间和状态展示使用 `TIMEZONE`，默认 `Asia/Shanghai`；身份资料路径使用 `OWNER_PROFILE_PATH`，默认 `.local/owner-profile.json`，未指定时兼容旧位置，不要求资料完整。
