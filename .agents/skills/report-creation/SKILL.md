# 报告创建

路径按项目 `AGENTS.md` 解析；`<PROJECT_ROOT>` 使用本轮服务提供的实际项目根目录。独立使用时，从本 `SKILL.md` 的真实技能目录（解析符号链接后）向上三级定位项目根目录，不依赖当前工作目录。日期理解和展示使用本轮 `TIMEZONE`，默认 `Asia/Shanghai`。

仅在主人要求创建或更新报告时使用。内容、来源和格式以本次请求为准；未指定时生成**独立静态 HTML 本地报告**，嵌入样式、脚本和图片，不依赖 CDN 或旁边的文件。`REPORT_SKILL_ENABLED` 默认关闭；启用后本地报告可联网获取当前任务所需资料、写入报告目录并发送附件，不依赖 GitLab 或线上发布开关。

## 本地报告

Claude Code、Codex、Grok 使用相同 agent_isolation 规则。工作目录是服务提供的 REPORTS_DIR（本次报告工作区），不是助手项目根目录；厂商原生沙箱关闭。

- 成品保存到本轮 REPORTS_DIR；宿主实际位置为 `<PROJECT_ROOT>/.project/reports/report-<任务编号>/`。使用有意义的文件名，不覆盖已有报告。
- 确认文件存在、可读且可独立打开。任务提供 tool_client.py 时，可用 send_file {path} 将附件发到已绑定的当前任务话题；服务也会自动交付未发送的报告产物并去重。创建本地报告本身授权本次交付，无需再问。
- 按根目录 `AGENTS.md` 执行：有任务服务入口时由服务设置相对文件路径与固定收件人，不直接运行带认证的 lark-cli；独立运行时在文件目录使用相对 --file。文件消息与说明文字分开发送；核实 `ok=true` 和实际消息 ID 后才称已发送。失败保留本地文件并说明实际步骤，不自行改走云空间或其他收件人。
- 本地报告不写入线上报告仓库，不提交、不 push。

## 线上报告

仅在主人**当前任务明确要求发布线上报告**时进入此流程。先确认本轮服务已提供 `REPORT_PUBLISH_ENABLED=true` 以及以下配置：

| 本轮配置 | 用途 |
| --- | --- |
| `REPORT_PAGES_REPO_URL` | 显式 SSH 仓库地址，无默认仓库 |
| `REPORT_PAGES_BRANCH` | 目标分支，由服务提供；配置默认值为 `main`，执行时不得写死 |
| `REPORT_REPOSITORY_DIR` | 服务确定的本地仓库绝对路径，执行时原样使用并核对归属 |

线上发布还要求 GitLab 功能和相应认证。任务提供 tool_client.py 时，先用 repository_prepare 准备配置目标的工作副本，使用 repository_git 的 add / commit / push 执行已授权发布；普通 glab / git 示例不表示可绕过服务入口。缺少配置或关闭发布时，说明缺失条件，可先完成本地报告；不猜仓库、不改用历史部署，也不自行打开开关。以上标识是运行参数，不是预设 shell 变量，执行前替换为本轮实际值并正确引用路径。

1. 按根目录规则检查配置目录以及 `.project/` 下同项目的旧工作区，以 origin 核对完整主机和项目。已有同项目就复用，不重复下载、不自动迁移或覆盖；与服务给出的路径冲突时先说明。仓库不存在时，仅为当前明确发布任务使用配置的 SSH 地址克隆到服务给出的目录。SSH 认证失败不改用 HTTPS。
2. 核对 origin、当前分支、工作区和本地提交。保留现有修改，不替用户提交。仅在配置分支的干净工作区正常 fetch，并以快进方式同步该配置分支；不强制切换或覆盖分支。更新失败时处理具体阻碍，不基于过期目录分配报告文件名。
3. 阅读目标仓库当前的 `README.md`、CI 和实际构建入口，按其命名、目录及编号规则生成报告。不要把模板的文件名或编号方式当作所有站点的要求；如使用连续编号，先核对现有序号与冲突。
4. 运行目标仓库要求的测试和构建，检查产物目录页、报告内容及脱敏结果。只提交本次报告及必需的构建变更，核对 diff 后 push 到**配置的目标分支**。当前明确的线上发布请求授权本次报告提交和 push，不扩大为修改部署权限、CI、其他报告或其他项目。因远端前进被拒时重新同步并核对命名；有冲突或未知改动时停止，不强推。
5. 回读实际提交及对应 CI、Pages 作业与部署结果，使用目标仓库核实后的实际 Pages 地址生成直达链接，文件名做 URL 编码。只有部署已核实才称已发布；等待、失败或权限不足时说明实际状态，不把预测链接称为上线。是否私有访问以当前站点设置为准，不假定任何固定域名或可见范围。

仓库操作遵守 `gitlab-assistant` bot skill，附件发送遵守 `feishu-private-assistant` bot skill 和根目录规则。不要在报告、文件名、提交信息或消息中写入凭证。已审阅消息按原文发送，不因机器人名称或署名配置变化而重写。
