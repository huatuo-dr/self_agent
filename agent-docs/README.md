# agent-docs 文档约定

本目录用于保存 AI 协作过程中的讨论方案。除本 `README.md` 外，新增文档须遵守以下规则：

1. 使用单个、自包含的 HTML 文件呈现；样式和脚本内嵌，文件可直接打开阅读，不依赖额外的源码目录。
2. 文件名以递增序号开头，名称使用中文，格式为 `序号-中文名称.html`，例如 `01-新嵌入式固件管理扩展方案.html`；不得使用英文名称或拼音代替中文名称。新讨论文档从当前最大序号继续递增，不复用已有序号；`00` 专用于模板，不参与讨论文档编号。
3. 新建文档复制 [`00-模板.html`](00-模板.html)，沿用其深色主题、布局、组件样式和内嵌交互。
4. 正文第一部分固定为 `0. 方案总览`，以图或表（也可图表结合）直观展示方案，让读者先理解当前问题、推荐做法及预期变化。按内容选择流程图、关系图、前后对比表或方案对比表，使用易懂的文字说明关键关系、收益与代价；不得仅用文字段落或装饰图替代。成文时须将模板图表替换为具体方案内容，后续正文章节从 `1` 开始递增，模板使用说明不得置于总览之前。
5. 本目录中的文档是 AI 讨论方案，并非最终落地方案，不能作为实现、验收或检查依据。实际要求以项目正式文档、规则及已落地的代码和配置为准。
